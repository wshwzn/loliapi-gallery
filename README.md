# loliapi-gallery

LoliApi（<https://www.loliapi.com/>）公开随机图服务的**图库索引页**，共 3999 张。
页面直接热链 LoliApi 的 CDN，**本仓库不存储任何图片文件**。

| 套系 | 说明 | 真实范围（实测） | 官方文档称 |
|---|---|---|---|
| `pc` | 电脑端壁纸（16:9 横屏） | 1..697 | 699 |
| `pe` | 手机端壁纸（竖屏） | 1..3069 | 2875 |
| `pp` | 二次元头像（400×400 正方形） | 1..233 | 218 |

## 索引规律

图片路径恒为 `/i/{set}/img{id}.webp` —— **分类和序号都写在 URL 里**。
域名只是镜像池，换哪个域名取到的都是同一个文件：

```
{esa,eo}-img.{loliapi.cn | loliapi.com | 521799.xyz | 544521.xyz | 20240828.xyz | iloli.love}
```

所以可以直接按构造地址取图，无需任何接口，例如：

```
https://esa-img.loliapi.cn/i/pc/img1.webp
https://esa-img.loliapi.cn/i/pe/img3069.webp
https://esa-img.loliapi.cn/i/pp/img233.webp
```

## 范围是怎么测出来的

用 CDN 的 `200 / 404` **三态探测**（没有调用 `/acg/` 接口去枚举），
`unknown`（429 限流、超时）单独记账并退避重试，不当作"不存在"。

> 注意：走 `/acg/?id=N` 接口时，**越界的 id 不会报错，而是静默返回一张随机图**。
> 所以官方文档里的"收录数量"不可信；直连路径的 404 才是可靠信号。

## 页面说明

单页 3999 张，`loading="lazy"` 懒加载 + 12 个镜像域名自动切换（失败即换下一个）。
格子里的图**就是原图**（未做缩略图、CDN 也没有缩放参数），
所以单张 pc 平均 775 KB、pe 平均 927 KB，手机上建议先用顶部分组按钮只保留一套。
